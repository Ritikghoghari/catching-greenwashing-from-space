NASA/IBM Prithvi-EO-2.0 Foundation Model: Zero-Shot vs. Linear Probing

Overcoming zero-shot foundation model spectral noise via biophysical gating and supervised probing heads

AI Innovation

1. The Problem Before (Zero-Shot Baseline) High Noise

When evaluated zero-shot across 290 mills, Prithvi achieved only a network mean rho = 0.172 and IoU = 0.086 (Syarimo baseline: rho = 0.597, IoU = 0.550).
Root Cause: Self-supervised Masked Autoencoders (MAE) flag all spectral differences (soil moisture, sun angle, seasonal crops, cloud haze) rather than true canopy loss. Fixed-percentile cutoffs generated false alarms.

2. What We Changed (Targeted Solutions) Novel Architecture

We kept the 300M parameter backbone frozen and tested two interventions on the IOI Syarimo benchmark:
• Technique 1: Biophysical ΔNDVI Gating + Otsu: Enforced vegetation loss constraint (ΔNDVI < 0) to eliminate non-biomass shifts.
• Technique 2: Supervised Linear Probing: Trained a lightweight 2-layer MLP classification head on frozen 1,024-dim embeddings with 5-fold cross-validation.

3. Empirical Benchmark Comparison (IOI / Syarimo Hotspot, Sabah) Breakthrough Results

Paradigm / Method Tested Spearman ρ Precision Recall IoU (Jaccard) Performance vs. Baseline

2. Biophysical ΔNDVI Gated + Otsu (Domain Prior) 0.772 0.923 0.387 0.375 Precision +30.0%

Core Takeaway for Thesis: Zero-shot foundation models struggle with tropical boundary noise. However, freezing the 300M backbone and training a lightweight probing head solves the trade-off, achieving 89.7% precision, 83.9% recall, and 76.5% IoU without expensive model retraining.
